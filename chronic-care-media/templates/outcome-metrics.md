# 模板：成效指標與成果呈現

素材要能被看見成效，建議在製作前就決定指標。以下為分層建議，**指標定義與目標值請依單位現況設定**。

## 指標分層

| 層次 | 指標範例 | 資料來源 |
|---|---|---|
| 產出 | 素材數量、疾病別覆蓋、系列數、語言版本數（國／台語） | 專案紀錄 |
| 觸及 | 候診區播放場次、LINE 開啟率、掃碼次數、發放份數 | 播放系統、LINE 後台、QR 統計 |
| 理解 | 衛教後 teach-back 通過率、知識問卷前後測、長者可理解度評分 | 衛教紀錄、問卷 |
| 行為 | 自我監測執行率、回診追蹤率、足部檢查／家庭血壓紀錄完成率 | 個管系統、問診紀錄 |
| 臨床 | 目標族群指標達成率變化（如 HbA1c、血壓、體重） | 院內資料庫（去識別彙整） |
| 品質 | 臨床審核通過率、素材更新時效、客訴／修正件數 | 審核紀錄 |

## 成果簡報頁型（現況→策略→成果）

1. 現況與困境：個案衛教識能落差、單張閱讀率低、人力有限
2. 改善策略：AI 輔助製作＋臨床審核機制＋系列化素材
3. 執行成果：產出數、觸及、理解、行為指標
4. 效益：人力與時間節省、一致性提升、可複製流程
5. 風險控管：臨床審核、合規檢核、AI 標示
6. 下一步：擴及病種、雙語化、成效追蹤

## 製作效率指標（內部管理用）

- 單一素材從需求到審核通過所需工作天
- 每份素材平均修正次數
- 重用率（角色卡、版型、提示詞庫被重複使用比率）
