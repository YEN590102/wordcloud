# 模板：30–60 秒衛教短影音（候診區／手機）

## 結構（以 45 秒為例）

| 段落 | 秒數 | 內容 | 鏡頭 |
|---|---|---|---|
| 1 情境 | 0–8 | 角色遇到日常狀況 | 中景，固定 |
| 2 重點一 | 8–18 | 示範行為 | 近景，輕微推近 |
| 3 重點二 | 18–28 | 第二個做法 | 中景 |
| 4 重點三 | 28–38 | 第三個做法 | 特寫手部動作 |
| 5 收束 | 38–45 | 複述行為目標＋何時就醫／聯絡方式 | 中景＋字幕 |

規則：每鏡 5–10 秒、**一鏡一動作**；字幕與旁白後製；結尾重複核心訊息一次。

## 分鏡表（可直接填）

| # | 時間 | 畫面描述 | 動作（單一） | 旁白（逐字稿） | 字幕 | 生成提示詞 |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |

## 單鏡提示詞

```
【角色卡外觀】。【單一動作】。
【台灣日常場景】，【時段】自然光。
【景別】固定／緩慢推近鏡頭。扁平化插畫風，色彩柔和。
【時長】秒。畫面不含文字、數字、標誌；動作緩慢自然；
不抖動、不變形、不多肢、角色外觀一致。
```

## 工作順序

1. 臨床人員確認旁白逐字稿與重點 → 2. 製作角色設定卡與定稿圖 → 3. 逐鏡生成（先短秒數測試）→ 4. 剪輯上字幕、配音、院所標示 → 5. 過 [品質與合規檢核](../references/quality-and-compliance.md) → 6. 發布。

## 範例：家庭血壓測量（行為目標示範）

- 1 情境：早晨，阿公起床坐在餐桌旁
- 2 重點一：坐姿、雙腳平放、手臂與心臟同高（動作由臨床人員審）
- 3 重點二：靜坐休息後再測量
- 4 重點三：把數值記在紀錄本（數字後製）
- 5 收束：「記得回診時帶紀錄本」＋聯絡方式
