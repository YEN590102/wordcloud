# CKM 衛教素材整套範例：「阿花嬤的一天，心腎代謝一起顧」

> 本範例依 `chronic-care-media` Skill 產出。**【院內填】** 為需由臨床人員依院內最新指引填入的欄位；本檔不含任何數值與用藥建議。
> 狀態：**草稿，待臨床審核**。

## 0. 專案摘要

| 項目 | 內容 |
|---|---|
| 主題 | CKM（心血管－腎臟－代謝症候群）整合照護衛教 |
| 對象 | 65 歲以上已有高血壓、糖尿病、慢性腎臟病或體重／血脂問題者，及其照顧者 |
| 總行為目標 | **回診時，讓醫療團隊把心、腎、代謝一起看**（帶齊紀錄與藥袋、不自行停藥或加藥） |
| 核心訊息 | 心、腎、代謝像三個互相影響的部位，一起顧，比分開顧更有效 |
| 素材組成 | 角色設定卡 1｜A4 單張 1｜LINE 圖卡 5｜短影音 3 支｜語音稿 1｜成效指標 |
| 場域 | 候診區電視、個管師衛教、LINE、診間發放 |
| 語言 | 國語（台語版由母語者校對後製作） |
| 風格 | 溫暖水彩插畫，米白底，3–4 主色（暖黃、柔綠、磚紅、深灰藍） |

```
阿花嬤：約 70 歲，灰白短捲髮，圓框老花眼鏡，淡綠色針織外套，
親切微笑，身形中等偏圓潤。
孫女小芸：約 25 歲，馬尾，米色針織衫，個性細心。
個管師：30 多歲女性，淺藍色護理服，胸前不放可辨識文字，笑容穩重。
場景：台灣家庭客廳（木質茶几、電風扇、窗邊盆栽）、傳統市場、社區活動中心、診間候診區。
```

```
站姿，正面全身，素色米白背景，溫暖水彩插畫風，邊線柔和，
```

## 2. A4 衛教單張（長者版）

**標題：看診帶三樣，心腎代謝一起顧**

| 區塊 | 內容 |
|---|---|
| 主插圖 | 阿花嬤與孫女在客廳，桌上有一個布袋，孫女協助整理（見下方提示詞） |
| 重點① | 帶藥袋與保健食品：看診時請把正在吃的藥、保健食品都帶來 |
| 重點② | 帶紀錄本：家裡量的血壓、體重，寫下來一起帶來 |
| 重點③ | 有疑問先問：不自己停藥、不自己加藥，也不自行買止痛藥或草藥 |
| 為什麼 | 心臟、腎臟、血糖體重互相影響，一次看清楚，醫療團隊才好一起幫您調整 |
| 何時聯絡 | 【院內填：紅旗症狀與聯絡方式】 |
| 檢查提醒 | 【院內填：CKM 定期追蹤檢查項目與頻率】 |
| 頁尾 | QR Code（後製）｜院所與個管師聯絡方式（後製）｜審閱日期｜版本｜「插圖為 AI 輔助生成，內容經臨床人員審閱」 |

**主插圖提示詞**

```
[阿花嬤外觀] 與 [孫女小芸外觀] 坐在台灣家庭客廳沙發上，
阿花嬤把藥袋與一本紀錄本放進一個布袋，孫女在旁微笑協助。
早晨窗邊柔和自然光，中景，主體偏左，右側留白供後製文字。
溫暖水彩插畫，米白背景，暖黃、柔綠、磚紅、深灰藍。
no text, no letters, no numbers, no logos, no watermark,
plain unlabeled pill bag, natural hands with five fingers, calm and respectful tone.
```

排版建議：標題 28pt 以上，內文 14pt 以上，深字淺底；紅旗症狀區使用框線＋圖示，不只靠顏色。

```
[阿花嬤外觀] 站在素色米白背景前，身旁有三個柔和半透明色塊（暖黃、柔綠、磚紅），
以細線條彼此相連，象徵三者互相影響，色塊內無任何圖案與文字。

no text, no letters, no numbers, no logos, no watermark, calm and respectful tone.
```

## 4. 短影音系列（3 支，各約 45 秒，16:9，候診區播放）

統一規格：每鏡 5–10 秒、一鏡一動作、固定或緩慢推近鏡頭、角色以定稿圖為參考、字幕與旁白後製。

### 第 1 支：心腎代謝是一家人（認識）

行為目標：理解三者互相影響，願意一次整合追蹤。

| # | 秒 | 畫面 | 動作 | 旁白 | 字幕 |
|---|---|---|---|---|---|
| 1 | 0–8 | 阿花嬤在客廳翻看藥袋，神情疑惑 | 翻看藥袋 | 阿花嬤吃了好幾種藥，常常搞不清楚為什麼。 | 吃了好多藥，為什麼？ |
| 2 | 8–18 | 個管師在診間微笑，桌上放簡單示意模型（無文字） | 向阿花嬤點頭示意 | 其實，心臟、腎臟和血糖體重，是互相影響的。 | 心、腎、代謝，互相影響 |
| 3 | 18–28 | 三個色塊以線條連接的水彩動畫 | 線條緩慢連接 | 一個地方出狀況，另外兩個也容易受到影響。 | 一起顧，更有效 |
| 4 | 28–38 | 阿花嬤點頭，個管師遞上紀錄本 | 接過紀錄本 | 所以，醫療團隊會一起幫您看、一起規劃。 | 團隊一起幫您 |
| 5 | 38–45 | 阿花嬤微笑拿著布袋走出診間 | 走向門口 | 看診時帶齊藥袋和紀錄本，心腎代謝，一起顧。 | 看診帶藥袋與紀錄本 |

單鏡提示詞示例（鏡 1）：

```
[阿花嬤外觀]，坐在台灣家庭客廳沙發上，低頭翻看一個藥袋，表情疑惑平和。
早晨自然光。中景固定鏡頭，輕微緩慢推近。溫暖水彩插畫風，色彩柔和。
5 秒。畫面不含文字、數字、標誌；動作緩慢自然；
不抖動、不變形、不多肢、角色外觀一致。
```

### 第 2 支：在家顧好自己（日常自我管理）

行為目標：每天固定時間完成家中量測並記錄。

| # | 秒 | 畫面 | 動作 | 旁白 | 字幕 |
|---|---|---|---|---|---|
| 1 | 0–8 | 早晨客廳，阿花嬤起床坐下 | 坐在椅子上 | 早上起床，先坐一下。 | 起床先坐一下 |
| 2 | 8–18 | 阿花嬤使用家用血壓計 | 袖帶綁在上臂 | 用家裡的血壓計，照醫護人員教的方式量。 | 照教的方式量 |
| 3 | 18–28 | 阿花嬤站上體重計 | 站上體重計 | 也可以固定時間量體重。 | 固定時間量體重 |
| 4 | 28–38 | 阿花嬤在紀錄本上寫字（字跡不可辨識） | 寫下紀錄 | 量完，寫在紀錄本上，不用怕寫不好。 | 寫下來就好 |
| 5 | 38–45 | 孫女拿起手機拍下紀錄本 | 拍照 | 家人也可以幫忙，看診時給醫護人員看。 | 家人一起幫忙 |

備註：量測姿勢、器材操作須由護理師或衛教師審閱動作；【院內填：量測時機與頻率、紀錄方式】。

### 第 3 支：看診不自己亂加減（用藥與回診）

行為目標：看診帶藥袋與保健食品，不自行停藥、加藥或購買止痛藥與草藥。

| # | 秒 | 畫面 | 動作 | 旁白 | 字幕 |
|---|---|---|---|---|---|
| 1 | 0–8 | 傳統市場，阿花嬤在藥攤前停下 | 看著攤位 | 鄰居介紹了一包「很有效」的藥。 | 別人說有效？ |
| 2 | 8–18 | 阿花嬤搖頭，把東西放回 | 放回物品 | 別急，先問問醫護人員。 | 先問醫護人員 |
| 3 | 18–28 | 診間，阿花嬤把藥袋與保健食品放上桌 | 拿出物品 | 看診時，把正在吃的藥和保健食品都帶來。 | 全部帶來看看 |
| 4 | 28–38 | 藥師與阿花嬤交談 | 藥師比手勢說明 | 藥師會幫您檢查，有沒有不適合一起吃的。 | 藥師幫您檢查 |
| 5 | 38–45 | 阿花嬤微笑，孫女點頭 | 微笑 | 不自己停藥、不自己加藥，有疑問就問我們。 | 有疑問就問我們 |

備註：腎臟病友避免自行服用止痛藥與來路不明草藥，為院內衛教重點之一，確切用語由臨床人員依院內版本確認；影片中不出現可辨識藥名。

## 5. 語音導讀稿（約 60 秒，國語，可用於候診區廣播）

```
各位長輩、各位家人，大家好。
今天跟您分享一件小事：看診的時候，請帶藥袋和紀錄本。
為什麼呢？因為心臟、腎臟，還有血糖和體重，是互相影響的。
醫療團隊看得越完整，就越能幫您一起調整。
第一，看診帶藥袋，連保健食品也一起帶來。
第二，在家量的血壓、體重，寫在紀錄本上。
第三，不自己停藥，也不自己加藥。有疑問，先問我們。
如果出現【院內核定的警訊】，請盡快聯絡我們。
再說一次：看診帶藥袋和紀錄本，心腎代謝，一起顧。
有任何問題，隨時問我們的團隊。謝謝您。
```

製作注意：語速偏慢；台語版由母語者校對；藥名與警訊文字逐字核對。
