# 素材類型與工具選擇

> 平台版本與功能變動快，下列為**選擇邏輯**，實際使用前請確認該平台當下的功能、授權條款與資料政策。**院內使用須先確認該工具是否經資訊單位許可。**

## 決策表

| 需求 | 建議做法 | 說明 |
|---|---|---|
| 單張／海報／LINE 圖卡 | AI 生**純插圖（無文字）**＋ PPT／Canva 後製文字 | 文字、數值、院徽一律後製，避免亂碼與錯字 |
| 步驟圖（吸入劑、注射、足部檢查） | 優先**實拍或專業插畫**；AI 僅作草稿 | 動作正確性風險高，須專業人員審 |
| 30–60 秒候診區短影音 | 逐鏡 AI 生成 5–10 秒片段＋剪輯軟體上字幕與旁白 | 一鏡一動作，角色以參考圖鎖定 |
| 語音導讀／廣播 | 文字轉語音（國語／台語） | 逐字稿先經臨床審核；語速偏慢 |
| 資訊圖表（比例、流程） | 直接用 PPT／Canva／Figma 製作 | 不需要生成模型 |
| 需要角色一致的系列 | 先做「角色設定卡」，再以參考圖生成 | 見 prompt-patterns §角色鎖定 |

## 選用順序

1. 能用現成模板／實拍解決的，不用 AI。
2. 需要情境插圖 → 圖像生成。
3. 需要動態示意 → 圖生影片（先有定稿圖，再讓它動），比文生影片穩定。
4. 需要旁白 → 文字轉語音，最後才做。

## 一般性建議（不指定廠牌）

- **文字渲染**：即使平台宣稱支援文字，衛教內容仍建議後製，避免錯字造成醫療誤導。
- **圖生影片**：先鎖定角色與場景定稿圖，影片只描述「動作與鏡頭」。
- **成本控管**：先出 4 張縮圖選構圖，定案後才生高解析度；影片先短秒數測試。
- **資料安全**：提示詞與參考圖不得含病人姓名、病歷號、可辨識臉孔或院內機密資料。
