# 品質與合規檢核（交付前必過）

## A. 臨床正確性

- [ ] 衛教訊息來源為院內最新指引／衛教單張／學會建議，已標註版本日期
- [ ] 無自創數值、劑量、頻率；數值皆由臨床人員填入
- [ ] 步驟類圖像（吸入劑、注射、足部檢查）動作與器材構造經專業人員（藥師／呼吸治療師／護理師／衛教師）審閱
- [ ] 未出現與診療建議衝突的畫面（如糖尿病個案畫面出現不符建議的飲食）
- [ ] 提醒「依個人醫囑調整」且不取代診療

## B. AI 生成常見瑕疵

- [ ] 手指數量、手勢、肢體比例正確
- [ ] 臉部無扭曲；不同鏡頭角色一致
- [ ] 器材（血壓計、血糖機、吸入器）構造合理，無假品牌或亂碼文字
- [ ] 食物、場景符合台灣生活情境
- [ ] 影片無閃爍、變形、突然換衣服或換人

## C. 長者與健康識能友善

- [ ] 每頁／每鏡頭只有 1 個重點
- [ ] 字體大（建議單張內文 14pt 以上、影片字幕畫面下方高對比）
- [ ] 對比充足（深字淺底），不使用僅靠顏色區分的資訊
- [ ] 語句短、用詞白話（如「血糖」「血壓」，少用縮寫）
- [ ] 影片節奏慢、語速適中，並有字幕
- [ ] 重要訊息重複一次（開頭預告、結尾複述）
- [ ] 建議以回覆示教（teach-back）設計互動問題

## D. 倫理與法規（請依院內法規部門意見為準）

- [ ] 不使用病人照片、姓名、病歷號、可辨識資訊
- [ ] 不使用真人藝人／醫師肖像或可混淆的相似臉孔
- [ ] 不暗示療效保證、不比較醫療院所優劣、不含商品促銷（依醫療法及醫療廣告相關規範，內容須經法規／公關單位確認）
- [ ] 角落註記「插圖為 AI 輔助生成，內容經臨床人員審閱」
- [ ] 版權：生成工具授權允許院內／對外使用；保留生成紀錄與提示詞
- [ ] 第三方素材（音樂、字型、圖片）授權清楚
