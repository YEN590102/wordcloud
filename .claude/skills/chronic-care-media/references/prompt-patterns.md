# 衛教素材提示詞寫法

承襲「具體名詞勝過泛詞」的原則：**5 個具體畫面要素，勝過 20 個形容詞。**

## 8 欄公式（圖像）

`主體 ＋ 動作 ＋ 場景 ＋ 光線 ＋ 構圖／景別 ＋ 風格 ＋ 色彩 ＋ 限制尾巴`

| 欄位 | 衛教情境寫法 | 範例 |
|---|---|---|
| 主體 | 年齡、性別、體型、穿著（台灣日常） | 約 70 歲的台灣阿嬤，花襯衫，戴老花眼鏡 |
| 動作 | **單一動詞**、單一行為目標 | 坐在客廳沙發，用手持小鏡子檢視腳底 |
| 場景 | 具在地感的生活場域 | 傍晚的台灣家庭客廳，木質茶几、電風扇 |
| 光線 | 柔和、溫暖、不戲劇化 | 窗邊柔和側光，溫暖色溫 |
| 構圖 | 清楚、留文字區 | 中景，主體偏左，右側留白供後製上字 |
| 風格 | 親切、乾淨 | 扁平化插畫、柔和邊線／溫暖水彩（擇一，系列固定） |
| 色彩 | 高對比、少色 | 3–4 主色，米白底 |
| 限制尾巴 | 見下方 | no text, no numbers… |

## 限制尾巴（醫療通用，每個提示詞必附）

```
no text, no letters, no numbers, no logos, no watermark,
correct human anatomy, natural hands with five fingers,
no distorted face, no extra limbs, calm and respectful tone
```

中文模型可用：`畫面不含任何文字、數字、標誌；人體比例正確、手指五指自然；表情平和；不誇張、不驚嚇。`

## 醫療專用負面清單

- 針筒、胰島素筆、吸入器、血糖機、血壓計：**構造常畫錯** → 以「generic device, no brand, simple shape」描述，或用實拍／專業素材疊加
- 藥丸／藥袋：避免生成可辨識藥名；用「plain unlabeled pill box」
- 食物：避免不符台灣飲食的畫面；指定「台灣便當、蒸魚、燙青菜、糙米飯」
- 人物：避免病容誇張、恐嚇式表情、體型羞辱
- 避免品牌、真人明星、現有 IP 角色

## 角色鎖定（系列用）

1. 先寫**角色設定卡**：姓名、年齡、外觀、服裝、固定配件（如老花眼鏡）。
2. 先生成正面／側面定稿圖。
3. 之後所有鏡頭以定稿圖為參考，提示詞開頭固定重複外觀描述。

```
角色：阿花嬤，約 70 歲，灰白短捲髮，圓框老花眼鏡，淡綠色針織外套，
親切微笑。（每個提示詞開頭重複）
```

## 影片提示詞（逐鏡）

公式：`主體＋單一動作＋場景＋鏡頭＋光線＋風格＋時長＋限制`

```
[角色卡外觀]。她拿起家用血壓計，坐姿將袖帶綁在左上臂，靜止呼吸。
台灣家庭客廳，早晨自然光。中景固定鏡頭，輕微推近。
扁平化插畫風，色彩柔和。5 秒。畫面不含文字、數字；動作緩慢自然；
不抖動、不變形、不多肢。
```

規則：**一鏡一動作**、鏡頭運動少而慢（長者觀看友善）、畫面不要快速閃切。

## 好 vs. 壞

| 壞 | 好 |
|---|---|
| `糖尿病衛教，漂亮，高畫質` | `約 70 歲台灣阿嬤坐在客廳，用小鏡子檢查腳底，柔和側光，扁平插畫，右側留白，no text` |
| 圖上要求「血糖 <100」 | 畫面無字，後製加上院內核定文字 |
| 一張圖同時畫飲食、運動、用藥 | 拆成 3 張，各一個重點 |

## 評分閘（交付前自評，滿分 10）

| 項目 | 分 |
|---|---|
| 單一行為目標清楚 | 2 |
| 具體在地場景（非泛用） | 2 |
| 含限制尾巴與留白 | 2 |
| 無文字／數值／品牌 | 2 |
| 長者友善（對比、簡潔、動作慢） | 2 |

低於 8 分，重寫再交付。
