# 模板：語音導讀／廣播稿

## 撰寫原則

- 每句 ≤ 20 字，一句一個意思
- 用「您」稱呼，語氣親切、不說教
- 先講「為什麼對您有幫助」，再講「怎麼做」
- 重點重複：開頭預告、結尾複述
- 專有名詞第一次出現時用白話解釋
- 台語版須由熟悉醫療用語的母語者校對，不直接依賴機器翻譯

## 稿件骨架（約 60 秒，國語）

```
【開場，5 秒】各位長輩、各位家人，大家好。今天跟您分享一件小事：【行為目標】。
【原因，10 秒】這樣做，可以幫助您【對個案有意義的好處，如：早一點發現問題】。
【做法，30 秒】第一，【重點一】。第二，【重點二】。第三，【重點三】。
【警訊，10 秒】如果出現【院內核定的警訊】，請盡快聯絡我們。
【收束，5 秒】再說一次：【行為目標】。有問題，隨時問我們的團隊。
```

## 製作注意

- 文字轉語音：選擇語速偏慢、咬字清楚的聲音，輸出前逐字聽稿
- 藥名、數值逐字核對，必要時以字幕呈現
- 背景音樂音量低於語音，或不使用
- 保留逐字稿存檔，供審核與日後更新
