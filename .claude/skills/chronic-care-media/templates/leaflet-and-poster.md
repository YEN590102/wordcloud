# 模板：衛教單張／海報／LINE 圖卡

## 版面骨架（A4 單面，長者版）

```
┌───────────────────────────────┐
│ 標題（一句行為指令，≤ 12 字）        │
├───────────────────────────────┤
│        主插圖（AI 生成，無文字）       │
├───────────────────────────────┤
│ ① 重點一（≤ 20 字）                 │
│ ② 重點二                            │
│ ③ 重點三                            │
├───────────────────────────────┤
│ 何時要回診／求助（紅旗症狀，院內核定）   │
│ 聯絡方式、QR Code（後製）            │
│ AI 輔助生成註記｜審閱日期｜版本        │
└───────────────────────────────┘
```

## 標題寫法

用「動詞開頭、可執行」：
- ✅ 每天檢查腳底，早發現早處理
- ✅ 在家量血壓，坐姿固定
- ❌ 糖尿病足部併發症之預防（太抽象）

## 插圖提示詞（填空版）

```
【角色外觀】正在【單一動作】，
場景：【台灣日常場景】，【時段】自然光。
中景，主體偏【左／右】，另一側留白供後製文字。
【風格：扁平化插畫／溫暖水彩】，3–4 主色，米白背景。
no text, no letters, no numbers, no logos, no watermark,
natural hands with five fingers, calm and respectful tone.
```

## LINE 圖卡（9:16 或 1:1）

- 一張一重點，連發 3–5 張成系列
- 第 1 張：情境＋問題｜第 2–4 張：做法｜最後一張：何時就醫與聯絡
- 每張底部放固定版型：院所名稱（後製）、審閱日期

## 範例：糖尿病足部檢查（行為目標示範）

- 標題：每天看腳底，小傷口別放著
- 重點：① 每晚用鏡子或請家人協助看腳底與趾縫 ② 穿合腳的鞋襪、勿赤腳 ③ 發現水泡、破皮或紅腫，當天聯絡醫療團隊
- 插圖：70 歲阿嬤坐在客廳用小鏡子看腳底，旁邊孫女蹲著協助
- 紅旗症狀與聯絡方式：由臨床人員依院內流程填寫
